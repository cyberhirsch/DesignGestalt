# Design & Gestalt

Course materials for **Design & Gestalt** — Smart Interactive Media, 1st semester, TH Rosenheim.

Published site: https://cyberhirsch.github.io/DesignGestalt/

## Contents

- `index.html` — course hub and schedule
- `tools/` — classroom tools
  - `style-lottery.html` — assigns each student a design style to present (62 movements)
  - `type-lottery.html` — the same for FontShop's 100 Best Fonts

The hub also links out to KernType (type.method.ac) by Method of Action as kerning
practice for Week 10.

Slide decks are added per week as they are finished.

## Notes

The lotteries keep their roster in the browser's local storage, so a round survives a
reload but lives only on the machine it was drawn on. Use **Show results** at the end of
a round to review and export the assignments.
