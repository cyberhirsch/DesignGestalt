Grid calculator

Convert between points, pixels, millimetres and inches. Then build a page grid with columns, fields and a baseline, check that it adds up in whole lines, and get the same numbers written out for Figma, Affinity and InDesign. Any field takes a unit: type 17mm or 48pt.

Units

1 pt = 1/72 inch ≈ 0.353 mm. Figma has no points: its PDF export writes 1 px as 1 pt, so in Figma you type the point values as pixels. CSS pixels are 1/96 inch. For a print image, pixels depend on the resolution: 300 ppi is the usual minimum.
